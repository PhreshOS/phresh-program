# Phresh Program

The official minimal starter Program generated by `phresh create`.

It demonstrates one Client and one Server communicating directly through the
standard PhreshOS Endpoint contracts.

## Create a Program

```sh
phresh create
```

The CLI bundles a verified release of this repository and creates the new
project without requiring a live template checkout.

## Structure

```text
phresh.config.ts
client/
├── app.tsx
├── index.html
├── main.tsx
└── style.css
server/
└── main.ts
scripts/
└── build.ts
```

The Server owns the counter. The Client renders it and communicates with its
paired Server. The example deliberately has no additional MVC hierarchy and no
registered Service.

## Development

```sh
bun install --frozen-lockfile
bun run verify
bun run dev
```

Build, attach the production definition, or package the Program with:

```sh
bun run build
bun run start
bun run pack
```

`verify` checks the source, builds both Endpoints, and validates the packaged
Program shape.

## Repository boundary

This repository owns the starter source distributed by the CLI. It remains a
complete ordinary Program rather than a second template model or generator-only
fixture.
